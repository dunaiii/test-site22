# Na-Trans — сайт вантажних перевезень (Варшава)

Односторінковий сайт-візитка. Дві мови (UA / PL) з перемиканням без перезавантаження, блок "Працюємо по всій Польщі", мобільна версія з нижньою панеллю дзвінка.

## Структура файлів

```
index.html   — весь сайт (HTML + CSS + JS в одному файлі)
van.jpg      — фото фургона в шапці сайту (лежить поруч з index.html, в одній папці)
```

Усі файли навмисно лежать в одній папці (без підпапок) — так простіше заливати вручну через веб-інтерфейс GitHub. Сайт не потребує збірки (build), сервера чи npm — це звичайний статичний HTML-файл.

## Як подивитись локально

Просто відкрийте `index.html` у браузері (подвійний клік), або, якщо хочете локальний сервер:

```bash
python3 -m http.server 8000
```

і відкрийте `http://localhost:8000`.

## Публікація на GitHub Pages

Архів `na-trans-site-repo.tar.gz` вже містить готовий git-репозиторій (з історією комітів та файлом `.nojekyll`, який вимикає непотрібну обробку Jekyll на GitHub). Розпакуйте архів — і репозиторій одразу готовий до заливки.

### Варіант A — через git (рекомендовано)

1. Розпакуйте архів у окрему папку.
2. Створіть новий **порожній** репозиторій на GitHub (без README, без .gitignore — щоб не було конфліктів): `github.com/new`, наприклад назва `na-trans-site`.
3. У розпакованій папці виконайте:
   ```bash
   git remote add origin https://github.com/<ваш-акаунт>/<назва-репо>.git
   git push -u origin main
   ```
4. У репозиторії на GitHub відкрийте **Settings → Pages**.
5. У розділі **Build and deployment → Source** оберіть **Deploy from a branch**, гілка — `main`, папка — `/ (root)`, натисніть **Save**.
6. За хвилину-дві сайт буде доступний за адресою:
   `https://<ваш-акаунт>.github.io/<назва-репо>/`

### Варіант B — без git, через веб-інтерфейс

1. Створіть новий репозиторій на GitHub.
2. Розпакуйте архів і перетягніть усі файли (`index.html`, `van.jpg`, `.nojekyll`, `README.md`, `.gitignore`) у вікно **Add file → Upload files** на сторінці репозиторію, натисніть **Commit changes**.
3. Далі кроки 4–6 як у варіанті A.

### Якщо сайт не відкривається

- Перевірте, що `index.html` лежить у **корені** репозиторію (не у підпапці) — інакше GitHub Pages його не знайде.
- Перше увімкнення Pages займає 1–3 хвилини; статус збірки видно у вкладці **Actions** репозиторію.
- Якщо змінили файли пізніше — після `git push` сайт оновлюється автоматично протягом хвилини-двох.

## Як вносити правки

- **Тексти**: у `index.html` кожен текстовий елемент має два атрибути — `data-uk="..."` (українська) та `data-pl="..."` (польська). Міняйте текст прямо в лапках.
- **Телефон**: номер `+48 784 727 385` зустрічається в кількох місцях (`tel:` посилання, підписи, JS-змінна `phoneNumber`) — при зміні номера краще пройтись пошуком (Ctrl+F) по файлу.
- **Фото фургона**: замініть файл `van.jpg` (у корені репозиторію) на власне зображення з такими самими пропорціями (приблизно 460×295) або відредагуйте CSS-клас `.hero-photo-frame img`. Головне — новий файл теж має називатись `van.jpg` і лежати поруч з `index.html`.
- **Кольори**: усі кольори зібрані на самому початку `<style>` у блоці `:root { --navy: ...; --amber: ...; }`.
- **Логотип**: SVG-іконка фургона (вигляд збоку) прописана прямо в HTML у двох місцях — в шапці (`<header>`) та у футері — шукайте `<div class="brand-mark">`.
- **Блок "Вся Польща"**: список міст-тегів (`Варшава`, `Краків`, `Вроцлав` тощо) знаходиться в секції `id="coverage"`, клас `.city-tags` — можна додавати/прибирати міста або міняти текст штампу `PL`.
